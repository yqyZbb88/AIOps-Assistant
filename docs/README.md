# 文档导航

第一次接触项目，从 [快速入门](quickstart.md) 开始。它解释组件、完成首次启动与连接，
并带你查看第一台主机和发送第一条问题；不需要先掌握 YAML、SSH 或模型配置。

## 推荐阅读顺序

- 接手者：项目整体交接 → 快速入门 → 架构说明 → 与接手职责相关的专题。
- 使用者：快速入门 → 使用指南 → 遇到问题时查对应专题。
- 部署维护者：快速入门 → 部署与升级 → 鉴权 → 数据库 → 本机测试与验收。
- 开发者：快速入门 → 架构说明 → 贡献约定 → 相关 API/配置专题 → 测试。

## 文档职责

`README.md` 是项目介绍与入口；`CONTRIBUTING.md` 是贡献约定；对外专题都放在 `docs/`。
一个主题的完整参数或操作步骤只在上表指定的专题维护，其它文档提供上下文和链接。
快速入门保留首次运行必需的少量命令，部署文档负责完整生命周期，不在使用指南重复配置表。
项目整体交接负责跨主题摘要和接手要求，环境、人员、凭据及当次工作区状态单独私下交付。

文档描述当前版本 `0.6.1`。配置指南的默认值来自仓库出厂配置，已有部署和本地编辑
可能不同；Compose 新部署另有独立安全模板，具体区别见配置与部署专题。

本机维护记录和旧资料存放在被 Git 和镜像构建忽略的 `docs/_local/`，不属于使用说明，
不作为当前行为依据。测试目录里的临时文件也不属于项目文档。
