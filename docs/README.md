# 文档导航

[17 项指标查询对照表](metric-queries.md)：列出控制台、AI、告警分析、Prometheus 规则与
Grafana 的表达式、单位、计算窗口及合理差异；从代码目录生成并检查漂移。

第一次接触项目，从 [快速入门](quickstart.md) 开始。它解释组件、完成首次启动与连接，
并带你查看第一台主机和发送第一条问题；不需要先掌握 YAML、SSH 或模型配置。

## 从零操作路线

第一次使用，按下面顺序操作：

1. [快速入门](quickstart.md)：安装前准备、取得文件、启动、远程隧道、Token 登录、首次指标与问答。
2. [Exporter 安装](deployment.md#独立-linux-测试主机安装-exporter) →
   [登记实际 Linux 主机](guide.md#第一次通过向导登记-linux-主机)。
3. [模型首次配置](console.md#第一次配置模型并验证问答) →
   [获取并核验 known_hosts](deployment.md#获取并核验-ssh-known_hosts) →
   [SSH 只读诊断](guide.md#第一次执行只读诊断)。
4. [让普通用户只看到指定主机](auth.md#第一次创建普通用户并验证隔离) →
   [人工审批](guide.md#第一次复现人工审批) →
   [规则自动处置](guide.md#第一次配置告警规则自动处置)。
5. [测试环境与告警练习](testing.md) → [备份恢复](database.md#备份)。

遇到 Grafana 密码无效先看 [旧数据卷与密码恢复](deployment.md#grafana-登录失败与旧数据卷)；
SSH 提示未知或不匹配主机密钥先看 [SSH 排障](troubleshooting.md#ssh-连接与-known_hosts-错误)。

## 文档职责


`README.md` 是项目介绍与入口；`CONTRIBUTING.md` 是贡献约定；对外专题都放在 `docs/`。
一个主题的完整参数或操作步骤只在上表指定的专题维护，其它文档提供上下文和链接。
快速入门保留首次运行必需的少量命令，部署文档负责完整生命周期，不在使用指南重复配置表。
项目交接清单负责跨主题摘要和接手要求，环境、人员、凭据及当次工作区状态单独私下交付。

文档描述当前版本 `0.6.2`。配置指南的默认值以 deploy/templates/assistant 模板及其未覆盖的程序默认值为准，已有部署可能不同。

本机维护记录和旧资料存放在被 Git 和镜像构建忽略的 `.runtime/`，不属于使用说明，
不作为当前行为依据。测试目录里的临时文件也不属于项目文档。
