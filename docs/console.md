## 进入与连接

Compose 部署始终验证身份，使用 `docker compose run --rm --no-deps init show-token`
获取管理员 Token；旧部署保留原设置。配置保存写入 `.runtime/config/`。启动、升级和凭据位置见 [deployment.md](deployment.md)。

1. 启动 Assistant 后访问 `http://127.0.0.1:8000/console`（按实际绑定地址调整）。
2. 页面外壳可匿名打开，但此时不包含主机、告警、会话、审批或配置数据。
3. 点击“连接”并输入当前 API Token。控制台用 `Authorization: Bearer <Token>` 请求数据；
   全部业务接口始终校验该 Token；普通用户只看到管理员授权的主机。
4. “断开”会清除当前标签页的 Token、会话内容、主机指标、告警、历史记录和管理员草稿；它不会撤销服务端 Token。
   更换 Token 也会先清理上一身份的数据和待确认操作，再重新加载；旧请求的结果和错误不会恢复这些数据。

右上角固定显示服务端核验的当前身份及实际角色，不从 Token 内容推断。身份切换/断开先清空
旧视图，业务请求返回 401 时清除身份与数据；管理员身份不自动成为审批人，不展示 Token 明文。

Token 只写入当前标签页的 `sessionStorage`，不写入 URL、HTML 或 `localStorage`。主题、密度、
默认页面、默认主机、刷新周期、趋势范围、收藏指标和总览卡片设置保存在版本化的
`localStorage`。浏览器中的偏好无论怎样修改，都不能扩大服务端的主机授权或命令白名单。
在共享电脑上使用后请断开连接并关闭标签页；浏览器扩展仍可能读取页面上下文，应按组织
安全策略管理客户端环境。

## 页面与数据来源

| 页面 | 主要用途 | 服务端数据 |
|---|---|---|
| 总览 | 健康、主机、收藏指标和最近动态摘要 | `/ready`、主机状态、指标摘要、告警与记录 |
| 主机 | 选择登记主机，查看核心指标、设备趋势、活动告警和诊断快捷入口 | `/hosts`、`/hosts/{id}/status`、指标趋势 |
| 问答诊断 | 创建/选择/改名/删除绑定主机的会话并发送问题 | `/sessions`、`/chat` |
| 审批 | 核对并决策，查看阶段进度与审批历史 | `/approvals`、`/approvals/{id}`、`/approvals/{id}/progress`、`/approvals/history` |
| 运维记录 | 按记录类型、状态和当前主机筛选告警、异常巡检、执行与 AI 建议 | `/alerts/history`、`/inspections/recent`、`/executions` |
| 系统管理 | 编辑受限配置草稿 | `/admin/config`，仅管理员可见 |
| 个性化 | 调整本浏览器的布局与展示偏好 | 仅浏览器本地；不上传偏好 |

页面顶部的主机选择影响主机详情、当前会话和记录筛选。创建会话时会固定 `host_id`；
之后的诊断和 Agent 工具均从该主机派生目标，切换顶部主机不会把旧会话改绑到新主机。
控制台不提供任意 SSH 地址、自由 PromQL、自由 Shell 或跨主机批量动作输入。

### 运行总览与状态判断

总览上方汇总全部授权主机的运行状态；收藏趋势和最近动态明确显示当前主机名称与 ID。
公开 `/ready` 探针的“平台就绪”独立于身份连接：已连接不代表所有监控依赖均就绪。
刷新状态展示摘要更新时间及自动刷新周期，查询进行中显示加载提示；摘要更新代表接口已返回，
并不代表所有监控数据都查询成功，仍需查看各项状态。未选择启用主机时，最近动态显示全部授权主机的历史记录。

未连接或整次刷新失败时，主机、告警和审批摘要显示“—”，不会将未查询的数据标成正常零。
已有连接但部分主机不可达或告警查询失败时，活动告警显示“—”或已知数量后加“+”，
同时注明未确认数据的主机数。只有完成全部启用主机的告警查询后，0 才表示无活动告警。

“需要关注”展示当前身份可见的待审批申请和全部启用授权主机的实时活动告警；历史告警
保留在当前主机的最近动态及运维记录中。点击主机行或“查看主机”会选择对应主机并进入详情；
“查看审批”进入原有审批列表，批准与拒绝仍需要既有确认流程。总览最多预览6台主机和6项待办，
完整内容通过已有页面查看。暂无可见主机时应联系管理员登记主机或调整访问授权。

导航支持折叠后就地展开；手机导航不继承桌面的隐藏文字状态。键盘用户可用页面首个
“跳到主要内容”链接跳过导航。连接与确认弹窗保留原生键盘行为；系统减少动画偏好会禁用界面动画。

复选项支持点击说明或键盘空格切换；窄屏表单和工具栏换行，聚焦表单时
为固定导航预留空间。凭据编辑、删除、轮换和撤销是独立操作，提交前核对对象。
主机详情在 Exporter 不可达、查询失败或活动告警查询失败时显示“—／活动告警未确认”，
只有成功查询后的空结果才显示活动告警为0。

### 指标、收藏和时间趋势

监控详情和收藏卡片显示计算窗口；CPU/IO/网络 rate 均为 5 分钟，趋势选择只改变展示范围，
告警持续时间是另一独立参数。磁盘摘要采用最坏挂载点，详情与曲线保留独立设备序列。
即时样本标注求值时间；预期标签缺失时显示该主机的 job/instance 及端口核对提示。
全量表达式、单位和入口差异见[查询对照表](metric-queries.md)。

缺失的指标显示为“—”，真实的零仍显示为 0。切换主机或会话时，迟到的旧响应
不会改写当前所选会话的内容或把状态归入另一台主机。切换主机或趋势范围时，收藏趋势
立即显示加载状态，不在新主机标签下继续展示旧曲线。

磁盘和网络吞吐速率使用后端已经换算的 MiB/s，不再按 B/s 解释；CPU 负载为每核负载，
网络错误为 errors/s。指标定义与完整单位见 [配置指南](configuration.md#内置指标目录)。

主机页的三个核心指标卡用于即时概览。下方“区间指标”可在已定义的指标目录中切换；
“加入收藏”会使该指标进入总览的收藏指标卡，最多 6 项，至少保留 1 项。收藏仅改变
浏览器展示，不修改 Prometheus 配置、巡检范围或告警规则。

趋势接口同时返回统计摘要与各设备逐点时间序列。折线横轴是真实采样时间，纵轴自适应
并留边距，带单位、时间刻度和悬停值；磁盘保留挂载点、设备、文件系统，网络保留网卡。
默认显示前 6 条，可勾选设备；缺失和非法样本保留断点。返回最多 32 条序列，超限明确提示。
默认时间窗 60 分钟，步长 `max(15秒, ceil(时间窗秒数/240))`，每条最多 241 个点。
主机页分别展示所选指标的即时值（含设备标签）和趋势状态。502 是查询失败，`no_data`
是无数据，0 是实际零值；收藏卡片也显示失败，先提供检查监控连接和刷新重试的建议，
底层错误放在“查看错误详情”中，不默认展开。没有 Swap 时显示“不适用”，不当作故障。

### 问答与诊断

第一次创建会话时：顶部选择主机 → 打开“问答诊断” → 在“主机会话”点“新建” →
确认会话标题和主机 → 输入问题 → 点“发送”。等待完整回答，再发下一条。
左侧点击已有会话可重新打开历史；需要好记的标题，点会话右上角“••• → 重命名”。
删除用同一菜单的“删除会话”，确认弹窗中的对象后执行；这会删除会话、关联消息和旧决策，
取消该会话未决申请。schema 8 独立保存的审批历史与执行记录按各自保留期保留，不能撤销
已经在远端执行的动作。不要用删除会话解决 unknown 状态。
首次关键词、模型和 SSH 问答分别见 [快速入门](quickstart.md#5-看第一台主机问第一个问题)、
[模型配置](#第一次配置模型并验证问答)、[只读诊断](guide.md#第一次执行只读诊断)。

- 先选择主机，再创建该主机的会话；多主机模式下不能用未绑定主机的会话发问。
- “快捷诊断”会预填受控问题，仍需用户确认发送。真正的诊断命令只能从已启用目录和该主机
  `allow.diagnostics` 中选择，不能从问题文本指定 SSH 目标或任意命令。创建会话期间
  连续点击不会重复创建，切换主机后也不会自动选回原主机的会话。
- 发送后立即在本地显示用户消息及加载动画；当前 `/chat` 返回的是完整回答，**不是流式
  Token 输出**。失败提示只更新发起请求的当前会话；输入框为空时恢复原问题，
  不覆盖正在编辑的草稿，也不向后来切换的会话恢复旧输入。超时不代表服务端已取消处理，重试前应检查记录。
- 删除确认固定针对弹窗中展示的会话，不随后台刷新改为其它会话。
- 会话消息会显示 `final`、`pending_approval`、`abandoned`、`unknown` 等状态。模型读取的
  历史窗口只包含最终完成的轮次，不会把未决审批当作已完成答案。

### AI 回复的 Markdown 展示

历史 Assistant 消息与新回复共用 Markdown 展示：支持标题、强调、删除线、列表、引用、
分隔线、表格、链接、行内代码和代码块。用户消息与请求错误仍显示纯文本。代码块与
宽表格在自身区域横向滚动，可通过键盘聚焦；代码不会执行。“复制代码”保留代码内容，
“复制原文”保留消息原始 Markdown。浏览器拒绝剪贴板时提供选中的只读文本供手动复制。
Windows 剪贴板可能将换行转换为 CRLF。

解析器 Marked 18.1.0 随项目本地提供，无 CDN 或前端构建步骤；展示组件仅使用分词结果，
通过安全 DOM API 创建允许的元素。原始 HTML 作为文字展示；图片只显示说明、不请求外部资源；
仅合法且不含用户名密码的绝对 HTTP(S) 链接可打开新标签页。相对链接及其他协议不激活。
数学公式、Mermaid 和代码语法高亮暂不支持。

正文超过 65,536 个 UTF-16 代码单元、渲染超过 5,000 个内容节点计数或嵌套超过 32 层时，
以及解析器加载／解析失败时，回退完整纯文本，仍可复制原文。消息存储与接口数据不变。

### 审批与记录

批准/拒绝的二次确认提交后，确认框立即关闭，人工审批顶部显示独立进度区。页面先显示
“等待服务端确认”，读到已持久化决策才显示“审批已通过/已拒绝”；每个动作分别显示执行中、
成功、失败或未知。已确认的决策移出未决卡片，执行成功后仍可能显示“正在等待 AI 后续反馈”。
AI 回复返回后单独展示，不将审批通过或 AI 的自然语言回复当作执行成功的依据。
审批请求最多等待 120 秒，期间每轮进度查询完成后间隔 1 秒再查，查询超时 5 秒；执行/模型
并不因此被取消。超时保留已确认事实并提示核对记录，禁止自动重试审批。进度读取失败不会伪造成功。

查看操作结果时，进入“运维记录”，先确认顶部当前主机，再选告警、异常巡检、执行等
记录类型，按需要筛选状态。核对事件时间、主机 ID 和审批/执行关联，不只看列表是否非空。
记录可能有条数限制、TTL 与刷新延迟；空列表先确认主机、类型和授权。
正常巡检不进入异常记录；历史 firing 也不表示当前仍异常。

审批前核对申请人、`host_id`、动作名和冻结参数。审批人与管理员是两种独立身份；
有管理权限不表示有审批权限。批准会恢复原 Agent 线程执行，拒绝不会执行写命令；
同一审批 ID 只能处理一次。过期、已处理或权限范围外的审批不会被当作成功，页面会刷新列表。
待审批 checkpoint 位于进程内，重启后不能续跑旧申请；若执行结果显示 `unknown`，先按
[数据库说明](database.md) 对照审计和目标状态，不要直接重试写命令。

“人工审批”下方的历史区域可按主机/审批状态筛选，每页 25 条。申请人、审批人、目标、
动作、申请/审批时间分别展示；审批通过与执行成功是两种不同结果。系统过期、撤销和队列淘汰
不冒充人工审批；无法判断的旧作废原因、归属和时间显示未知。历史持久化及保留期见[数据库说明](database.md)。

规则和 Agent 的执行结果采用相同口径：正常退出 0 才显示成功；非零显示失败并保留
退出码；未收到退出状态、派发后断线或超时显示结果未知。命令失败也可能已经产生部分
副作用；审批通过、AI 反馈已返回都不能代替动作执行结果。旧的空失败详情无法还原退出码，
不会因为升级而改写为成功。

运维记录只把异常巡检的指标快照显示为有界预览；“展开指标快照”和“查看原始 JSON”
分别提供完整数据。长字段会换行，服务端文本通过 `textContent` 等安全 DOM API 渲染，
不作为 HTML 执行。记录中的历史告警与 Prometheus 的实时活动告警不是同一数据源。

## 系统管理：配置草稿与独立凭据保存

管理员身份必须来自 Token→身份映射并列在 `auth.admin_identities` 中。普通 Token 不显示
“系统管理”；业务接口始终要求有效 Token，管理接口进一步要求管理员身份。管理页分区为：

1. **安全与开关**：强制身份校验说明、审批模式与身份、管理员身份、告警入口身份、LLM、
   聊天 Agent、巡检、自动处置总开关及三类命令目录开关。
2. **告警规则**：新增、复制、编辑、禁用或删除规则，选择登记主机、规则动作和参数。
3. **命令目录**：在规则动作、Agent 动作和只读诊断命令之间切换，维护启用状态、说明、
   模板和参数约束。模型只能调用启用且获主机授权的命令。
4. **主机授权**：按登记主机分别勾选诊断、规则动作、Agent 动作白名单。页面不编辑主机
   地址或 Prometheus 目标；SSH 关联在“SSH 凭据”中修改。
5. **监控主机**：登记/删除主机并管理托管采集；自管 Compose 模式可输入新 Exporter
   `主机:端口`。可选 SSH 只使用已有凭据 ID，诊断授权须先通过不执行命令的 SSH 检查。
6. **SSH 凭据**：新增、更新、删除页面凭据，并修改已有主机的关联。
7. **用户 Token**：按身份生成、轮换、撤销页面 Token；部署凭据只读。
8. **模型配置**：OpenAI 兼容模型 参数与密钥管理；显式按钮测试连接。
9. **用户主机授权**：按稳定身份勾选主机或撤销全部授权；默认拒绝。管理员显示全部主机只读选项。与“逐主机授权”的命令白名单分别配置。

“删除主机登记”只移除 Assistant 登记，Prometheus 继续采集；对应项目托管目标可明确选择
“删除登记并停止托管采集”，无登记引用的托管目标另有“停止托管采集”。操作会确认影响，
不删除已有样本或历史。先撤销用户主机授权、移除规则引用，并处理未决审批和运行/未知执行。
系统不自动级联删引用，候选清单仍须保留至少一台启用主机；冲突或校验失败保留原配置。
外部 Prometheus 不由页面修改；发现服务故障时仍可查看离线登记。托管目标通常在 30 秒内
被 file_sd 发现更新。页面不提供停用或迁移现有主机 ID 的入口。
SSH 检查会尝试连接目标并验证主机密钥/认证，但不会执行远程命令；未经真实环境授权
不要点击。新增成功也不代表 Prometheus 已发现目标或 Exporter 可达。

管理页按“安全与策略／主机与授权／凭据与模型”分组，九个分区与键盘切换保持完整。
页面明确显示系统级作用范围，不随顶部当前主机切换；涉及主机的操作在对应区域选择目标。
安全与功能、自动处置面板按内容自然高度排列，手机导航分组同排展示。

配置分区（含用户主机授权）切换只改变可见表单，未保存修改仍保留在同一份内存草稿中。
进入监控主机、SSH、Token 或模型分区前须先保存或放弃未保存草稿。
顶部“保存并生效”一次提交完整草稿；有草稿时“重新加载配置”变为“放弃修改并重载”，
经确认后才舍弃修改；请求失败则保留草稿和未保存标记。关闭或刷新有草稿的页面时浏览器会提示。
保存期间表单锁定，版本冲突与保存结果在相关区域提示。

监控主机与凭据／模型分区隐藏全局保存动作，使用各自独立按钮。Token 轮换、撤销与 SSH
凭据删除需确认；服务端继续执行原有约束检查。凭据保存失败后不自动重试写请求，可点击
“重新加载凭据状态”核对最新版本和结果；一次性 Token 仍只显示当次、离开即清除。

保存流程由服务端完成：比较磁盘 revision → 合并浏览器可编辑字段与保留字段 → 使用现有
解析器及跨文件规则校验 → 备份有变化的原文件到 `data/config-backups/<UTC 时间>/` →
逐文件原子替换，最后切换运行快照。写入异常会尝试从备份回滚。**这是配置写入保护，不是数据库备份，也不是
跨文件/断电原子事务。** 当前仅支持单 worker、单实例管理写入；不要让其他进程同时改
这些 YAML 文件。

| 提示或状态 | 含义与处理 |
|---|---|
| 401 | 未带 Token 或 Token 无效；重新连接。 |
| 403 | Token 有效但身份不是管理员；联系现有管理员，不要改客户端页面绕过。 |
| 409 | revision 冲突、未决审批或业务请求正在执行；核对配置或等待请求结束。 |
| 422 | 某个字段、命令参数或跨文件引用无效；按错误提示修正，不能删除仍被规则/主机引用的命令。 |
| 503 | 管理配置文件或 round-trip YAML 能力不可用；检查服务日志与部署依赖。 |
| “磁盘配置尚未应用” | 磁盘 revision 与运行 revision 不同；在配置分区尝试“应用磁盘配置”，不支持热更新的字段会使整批应用被拒绝。 |

请求超时不等于服务端保存或审批已取消。对可能写入的操作，先重新加载配置 revision、
审批列表或执行记录核对结果，再决定是否重试，避免重复提交。

页面不提供进程重启或备份恢复按钮。用户主机授权和自动处置开关在保存成功后立即生效，
旧 Token 可能失去访问权；应重新连接并核对运行状态。监听、SQLite/日志路径和环境密钥
仍需重启。生产环境若需要远程主机启动、重启或修改，应另行取得明确授权，不能把配置保存等同于授权。

## 使用范围

控制台显示 Agent 的最终回答；等待期间显示状态提示。待审批申请仅在当前进程有效。
服务使用单 worker。键盘可用 Tab 聚焦分区；左右箭头、Home、End 切换当前分区或命令子分区。

## 管理员配置操作

### 第一次配置模型并验证问答

先从模型服务提供方取得三样信息：API Key（调用密钥）、Base URL（接口地址）、模型名。
服务需要支持 Chat Completions。要让 AI 自己查指标或请求诊断，还需要“工具调用”能力，
也就是模型能请求系统使用已提供的查询工具。模型名按服务提供的完整名称填写。

1. 管理员连接后进入“系统管理”，先处理其它分区未保存的草稿，再打开“模型配置”。
2. 首次选择“密钥操作 → 替换密钥”，在“新 API Key”填写真实密钥，不含 Bearer 前缀。
3. 填写下表，点击分区内“保存模型配置”。该分区独立保存，不点顶部配置保存。
4. 点击“测试已保存的模型连接”，等待“模型连接正常”。它只测试一次短文本响应，
   不验证工具调用、SSH 或完整告警分析。失败按 [模型排障](troubleshooting.md#模型连接或工具调用失败) 定位。
5. 到“安全与开关”开启“聊天 Agent”，需要告警 AI 分析时再开启“LLM 分析”，
   点击顶部“保存并生效”。两个开关用途不同。
6. 选择有真实指标的测试主机，在“问答诊断”新建会话，问
   “请查询这台主机当前 CPU 和内存指标，再解释是否存在异常”。
   核对回答主机、采样时间和指标事实；只回复空泛建议时仍需查工具能力。

| 字段 | 首次填写方法 |
|---|---|
| Base URL | 接口根地址，例如自建接口 http://model.example/v1；不追加 /chat/completions |
| 模型名 | 服务实际提供的完整名称，区分大小写并去掉额外空格 |
| 超时（秒） | 可先用 30；限制每次模型请求的等待时间，一轮对话可能会请求多次 |
| 重试次数 | 可先用 2；失败时区分服务不可达、鉴权和模型参数问题 |
| 最大输出长度 | 可先用 2048，按模型上下文和输出限制调整 |
| 高级：输出长度参数 | 根据服务文档选 max_tokens 或 max_completion_tokens，只发送所选字段 |

保存后表单不回显明文 key 是正常行为。更新其它参数时选“保留密钥”；轮换时选“替换密钥”；
“明确清除密钥”会让该页面来源无密钥，不回退部署环境密钥。
实际发起的连接测试、聊天和告警分析可能消耗模型额度，保存参数本身不请求服务。

### 第一次保存 SSH 凭据

先按 [获取并核验 known_hosts](deployment.md#获取并核验-ssh-known_hosts) 准备公钥行。
凭据 ID 是方便主机引用的名称，如 linux-test-ssh；用户名是目标 Linux 的登录账户。
密码认证无需上传私钥；私钥认证上传用户私钥而不是用户公钥，当前不支持私钥口令。
两种方式都必须粘贴完整可信 known_hosts，不能填文件路径、SHA256 指纹或本机用户的 .pub。

保存后去新增向导选择凭据，或在本分区下方为已有主机“更新关联”，再执行显式连接测试。
没有主机关联时仅保存凭据不会连接任何主机；认证通过也不会自动获得命令权限。
完整步骤见 [准备并关联 SSH 凭据](guide.md#准备并关联-ssh-凭据)。

### 凭据与配置操作的保留行为

“SSH 凭据”的“编辑”会定位到表单、标明当前编辑 ID 并锁定 ID；用户名和认证方式可编辑。
自动刷新不会重建正在编辑的表单或推进提交 revision；并发修改会在保存时返回 409，须
重新加载后核对。提交、取消、离开分区或断开会清空敏感输入；保存失败保留服务端原凭据，
提示重新加载核对。部署文件中的凭据只读；需要轮换时新建页面凭据，再明确更新主机关联。

SSH：填写唯一 ID、用户名，选择密码或上传无口令私钥，并粘贴已核验的 `known_hosts`。
更新时密码/私钥/known_hosts 留空或不上传表示保留；认证方式改变时须提供新凭据。
保存后主机向导立即可选该 ID；已有主机在下方更新关联。被主机引用的凭据不能删除（409）。
“测试已保存的 SSH 连接”仅握手、校验主机密钥和认证；不会执行命令或修改授权。
未知和不匹配的主机密钥继续拒绝，凭据保存使旧 SSH 检查票据失效。

Token：输入身份名后生成随机 Token，创建和轮换只显示一次明文，请当场复制给对应用户。
明文不写入 sessionStorage/localStorage，切换分区、离开管理页、断开连接或更换身份会清除。
“轮换”使旧 Token 失效，“撤销”使后续请求失效；该用户以前的会话仍然保留。新增身份在“安全与开关”
中按需授权管理员或审批人，普通用户默认没有这些角色。部署管理员与 Webhook Token 只读。

身份名区分大小写，Alice 与 alice 是不同身份。角色名单中的旧身份若已无有效 Token，
会显示“无有效 Token”和大小写提示，管理员可在“安全与开关”取消勾选。
保留已有失效审批项不会阻塞用户主机授权保存，也不会把角色转给相似拼写的新身份；
新加入审批名单的身份必须有对应 Token。若希望 Alice 参与审批，应显式勾选 Alice，
并按需移除旧 alice，不能仅依赖主机访问授权。


模型：支持 OpenAI 兼容模型 API Key、Base URL、模型名、超时、重试、最大输出长度。密钥选择
“保留”“替换”或“明确清除”；清除不会回退到环境密钥。保存不请求模型。
“测试已保存的模型连接”才发送一次短请求（10 秒、无重试、16 输出 Token），失败显示通用提示。
Base URL 填接口根地址（例如自建服务的 http://model.example/v1），不要追加 /chat/completions。
高级选项决定输出长度使用 max_tokens 还是 max_completion_tokens，服务只发送所选字段。
完整 Agent 功能要求模型支持标准工具调用；仅能文本聊天的接口无法运行 Agent 工具。
页面配置整组优先于环境，修改环境不会覆盖页面配置。
配置后在“安全与开关”按需开启聊天 Agent 与 LLM 分析。Token/模型/SSH 保存均校验 revision，
有运行写操作或未决审批返回 409，校验或持久化失败保留旧运行快照。

页面通知保留在右侧内容区、标题栏下方，按原边距对齐；滚动时固定悬浮，不覆盖左侧导航。
侧栏收起、窗口缩放与提示换行时自动重新对齐，关闭后释放占位。前端资源使用内容版本标识，
避免更新页面后复用旧样式。SSH 表单在提交前检查新建凭据的
必填项，缺少 known_hosts 等内容时保留当前输入并聚焦对应字段。密码认证无需上传私钥，
但密码和私钥认证都需要可信 known_hosts 来验证服务器身份；它是主机公钥记录，
不是用户的登录私钥。新建时粘贴经管理员核验的内容，更新已有凭据时可留空保留。
